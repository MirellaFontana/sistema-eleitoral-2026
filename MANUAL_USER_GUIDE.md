## Introdução

O **Eleito Online** é uma plataforma completa de gestão de campanhas eleitorais brasileiras. Ela reúne em um único sistema:

- Cadastro de eleitores, apoiadores e lideranças
- Gestão de tarefas e agenda
- Comunicação com a equipe
- Inteligência de monitoramento de notícias e concorrentes
- Consultoria jurídica eleitoral com IA
- Criação de peças de marketing com revisão de compliance
- Planejamento de impulsionamento de anúncios

O sistema utiliza **inteligência artificial** em diversas funcionalidades: geração de briefings diários, análise de narrativas, recomendações estratégicas, sugestão de respostas para cidadãos, revisão jurídica de peças publicitárias, geração de imagens e planos de impulsionamento.

### Papéis do Sistema

| Papel | Descrição | Acesso Principal |
|-------|-----------|------------------|
| Coordenador de Campanha | Administrador geral da campanha | Acesso total a todas as funcionalidades |
| Candidato | O candidato da campanha | Visualização de briefings, decisões e recomendações |
| Coordenador de Marketing | Responsável pelo marketing | Marketing, peças, impulsionamento, comunicação |
| Redator de Marketing | Criação de conteúdo | Peças de conteúdo, marketing, comunicação |
| Advogado Responsável | Jurídico da campanha | Módulo jurídico, revisão de peças, compliance |
| Assistente Jurídico | Apoio jurídico | Consultas jurídicas, dossiê |
| Coordenador de Campo | Gestão de campo | Cadastros, campo, demandas, mapa |
| Agente de Campo | Trabalho de campo | Registro de eventos, escuta de campo |
| Tesoureiro | Finanças da campanha | Visualização geral, auditoria |
| Assessor de Comunicação | Comunicação institucional | Mensagens, avisos, monitoramento |
| Analista de Dados | Análise estratégica | Inteligência, monitoramento, propostas, narrativas |

## Acesso ao Sistema

### 2.1 Primeiro Acesso (Convite)

O acesso ao sistema é feito exclusivamente por **convite**. O coordenador de campanha envia um convite por e-mail através do módulo de Usuários.

**Passos:**

1. Você receberá um e-mail com o assunto "Convite — Gestão Eleitoral".
2. Clique no link do e-mail. Você será redirecionado para a tela de definição de senha.
3. Defina uma senha com no mínimo 8 caracteres.
4. Após definir a senha, você será redirecionado para o sistema já autenticado.

### 2.2 Login

**Passos:**

1. Acesse **eleito.online** no navegador.
2. Na tela de login, preencha seu **e-mail** e **senha**.
3. Clique em **"Entrar"**.
4. Você será redirecionado para a **Sala de Decisão** (tela inicial).

**Dica:** O sistema funciona em celulares e tablets. Use o menu hambúrguer (☰) no canto superior esquerdo para abrir a navegação em telas pequenas.

### 2.3 Esqueci Minha Senha

**Passos:**

1. Na tela de login, clique em **"Esqueci minha senha"**.
2. Digite o e-mail cadastrado e clique em **"Enviar link"**.
3. Verifique sua caixa de entrada (e spam). Você receberá um e-mail com o link de redefinição.
4. Clique no link e defina a nova senha (mínimo 8 caracteres).

**Importante:** O link de redefinição é enviado apenas para e-mails já cadastrados no sistema. Se você não recebeu o e-mail, confirme com o coordenador se seu e-mail está correto.

### 2.4 Navegação

O sistema possui uma **barra lateral** (sidebar) escura à esquerda com todos os módulos organizados em grupos. Clique no nome do grupo para expandir/recolher os itens. O item ativo fica destacado em verde. No topo da página, há uma **barra de busca** para localizar pessoas rapidamente, um **sino de notificações** e o botão de **sair**.

## Sala de Decisão

A Sala de Decisão é a **tela inicial** do sistema. Ela apresenta um painel com quatro quadrantes que resumem o estado atual da campanha:

| Quadrante | O que mostra |
|-----------|-------------|
| Decisões pendentes | Lista de decisões estratégicas aguardando posicionamento do candidato ou coordenador |
| Recomendações recentes | Últimas recomendações geradas pela IA com base nos dados da campanha |
| Alertas ativos | Alertas de monitoramento que exigem atenção (menções negativas, prazos, etc.) |
| Briefing do dia | Resumo diário gerado por IA com os principais pontos da campanha |

**Passos:**

1. Ao entrar no sistema, a Sala de Decisão carrega automaticamente.
2. Clique em qualquer item para ir direto ao módulo correspondente.
3. O briefing diário é gerado automaticamente pela IA. Clique em **"Gerar briefing"** se quiser um novo.

**Dica:** Volte à Sala de Decisão a qualquer momento clicando em "Sala de Decisão" no menu lateral.

## Estratégia

### 4.1 Decisões

O módulo de Decisões permite registrar, acompanhar e decidir sobre questões estratégicas da campanha. Cada decisão tem um status (pendente, aprovada, rejeitada) e pode incluir argumentos a favor e contra.

**Passos:**

1. No menu lateral, clique em **Estratégia → Decisões**.
2. Você verá a lista de decisões com status, data e responsável.
3. Para criar uma nova decisão, clique no botão **"Nova decisão"**.
4. Preencha o título, descrição, contexto e argumentos. Clique em **"Salvar"**.
5. Para aprovar ou rejeitar, abra a decisão e use os botões de ação correspondentes.

### 4.2 Recomendações

A IA analisa os dados da campanha (monitoramento, base de conhecimento, diretrizes) e gera **recomendações estratégicas** com ações concretas. Cada recomendação passa por um ciclo: gerada → em análise → aceita/rejeitada → implementada.

**Passos:**

1. Acesse **Estratégia → Recomendações**.
2. Clique em **"Gerar recomendações"** para a IA criar novas sugestões.
3. Revise cada recomendação. Você pode **aceitar**, **rejeitar** ou deixar **em análise**.
4. Recomendações aceitas podem ser marcadas como **implementadas** quando a ação for executada.

**Dica:** As recomendações são mais relevantes quando a Base de Conhecimento e as Diretrizes estão bem preenchidas.

## Administração

### 5.1 Cadastro de Campanha

Tela central para configurar os dados da campanha: nome do candidato, nome de urna, número, cargo, UF, partido, coligação e CNPJ. Também é onde se gerenciam as **chaves de API** dos serviços de IA (Anthropic, Google Gemini, OpenAI, Grok).

**Passos:**

1. Acesse **Administração → Cadastro de campanha**.
2. Preencha ou atualize os dados da campanha nos campos disponíveis.
3. Na seção **"Chaves de API"**, cadastre as chaves dos provedores de IA que a campanha utiliza.
4. Clique em **"Salvar"** para gravar as alterações.

**Alerta:** As chaves de API são armazenadas de forma criptografada. Nunca compartilhe suas chaves com terceiros.

### 5.2 Usuários

Gerencie quem tem acesso à campanha. Apenas o **Coordenador de Campanha** pode convidar novos usuários e alterar papéis.

**Passos:**

1. Acesse **Administração → Usuários**.
2. Você verá a lista de usuários com nome, e-mail, papel e status.
3. Para convidar, preencha o e-mail, selecione o **papel** e clique em **"Convidar"**.
4. O convidado receberá um e-mail com link para definir a senha e acessar o sistema.
5. Para alterar o papel de um usuário existente, clique no papel atual e selecione o novo.

**Dica:** Cada usuário pode pertencer a apenas uma campanha por vez. Para trocar de campanha, é necessário novo convite.

### 5.3 Funções e Permissões

Visualize a matriz de permissões do sistema: quais papéis têm acesso a quais funcionalidades. A criação de funções customizadas é feita nesta tela.

**Passos:**

1. Acesse **Administração → Funções e permissões**.
2. Visualize a tabela com papéis nas linhas e funcionalidades nas colunas.
3. Para criar uma nova função, clique em **"Nova função"**, defina nome e permissões.

### 5.4 Trilha de Auditoria

Registro cronológico de todas as ações importantes realizadas no sistema (quem fez o quê e quando). Útil para rastreabilidade e conformidade legal.

**Passos:**

1. Acesse **Administração → Trilha de auditoria**.
2. Use os filtros de data, usuário e tipo de ação para encontrar registros específicos.
3. Cada entrada mostra: data/hora, usuário, ação realizada e detalhes.

### 5.5 Quarentena de Dados

Quando dados pessoais são solicitados para exclusão (LGPD), eles vão para quarentena antes da remoção definitiva. Isso permite revisão e recuperação dentro do prazo legal.

**Passos:**

1. Acesse **Administração → Quarentena de dados**.
2. Visualize os registros em quarentena com data de entrada e prazo de exclusão.
3. Para restaurar um registro antes do prazo, clique em **"Restaurar"**.

### 5.6 Retenção de Dados

Configure por quanto tempo cada tipo de dado é mantido no sistema antes da exclusão automática, em conformidade com a LGPD e a legislação eleitoral.

**Passos:**

1. Acesse **Administração → Retenção de dados**.
2. Defina o prazo de retenção para cada categoria de dados.
3. Clique em **"Salvar"** para aplicar as configurações.

## Cadastros

### 6.1 Eleitores

Cadastro central de eleitores. Permite buscar, filtrar, cadastrar e visualizar os detalhes de cada eleitor, incluindo dados pessoais, endereço, contato e histórico de interações.

**Passos:**

1. Acesse **Cadastros → Eleitores**.
2. Use a barra de busca para encontrar um eleitor pelo nome, e-mail ou telefone.
3. Para cadastrar um novo eleitor, clique em **"Novo eleitor"** e preencha os campos.
4. Clique no nome de um eleitor para ver seus detalhes e histórico completo.

**Dica:** A busca global no topo da página também encontra eleitores. Digite pelo menos 2 caracteres.

### 6.2 Apoiadores

Eleitores que declararam apoio à campanha. Além dos dados básicos, o perfil do apoiador inclui nível de engajamento, habilidades, disponibilidade e área de atuação.

**Passos:**

1. Acesse **Cadastros → Apoiadores**.
2. Visualize a lista com nome, bairro, nível de engajamento e status.
3. Para promover um eleitor a apoiador, vá ao perfil do eleitor e clique em **"Tornar apoiador"**.
4. Para registrar atividades do apoiador, abra o perfil e use a seção de histórico.

### 6.3 Lideranças

Líderes comunitários e figuras de influência na região. O cadastro inclui área de influência, bairros de atuação, estimativa de votos influenciáveis e vinculação com apoiadores.

**Passos:**

1. Acesse **Cadastros → Lideranças**.
2. Cada liderança mostra: nome, região de influência, apoiadores vinculados e estimativa de alcance.
3. Para cadastrar, clique em **"Nova liderança"** e preencha os dados.
4. Vincule apoiadores existentes à liderança para mapear a rede de influência.

## Gestão

### 7.1 Tarefas

Gerenciamento de tarefas da campanha em formato de lista. Cada tarefa tem título, descrição, responsável, prazo, prioridade e status (pendente, em andamento, concluída).

**Passos:**

1. Acesse **Gestão → Tarefas**.
2. Veja a lista de tarefas com filtros por status, responsável e prioridade.
3. Clique em **"Nova tarefa"** para criar. Preencha título, descrição, responsável e prazo.
4. Para atualizar o status, clique na tarefa e altere o campo de status.
5. Tarefas concluídas ficam com indicação visual de "done".

### 7.2 Agenda

Calendário de compromissos da campanha. Visualize eventos por dia, semana ou mês. Inclui comícios, reuniões, entrevistas, prazos legais e outros compromissos.

**Passos:**

1. Acesse **Gestão → Agenda**.
2. Navegue pelo calendário usando as setas ou alternando entre visões (dia/semana/mês).
3. Clique em um dia para criar um novo evento. Preencha título, horário, local e descrição.
4. Eventos aparecem no calendário com cores indicando o tipo.

### 7.3 Escuta de Campo

Registro de informações coletadas em campo pelos agentes: sentimento dos eleitores, demandas da comunidade, percepções sobre a campanha e concorrentes. Cada registro inclui bairro, tema, sentimento (positivo/neutro/negativo) e observações.

**Passos:**

1. Acesse **Gestão → Escuta de campo**.
2. Veja a lista de registros de campo com data, bairro, tema e sentimento.
3. Clique em **"Novo registro"** para adicionar uma escuta.
4. Preencha o bairro, tema observado, sentimento e observações detalhadas.

**Dica:** Os registros de campo alimentam as recomendações da IA. Quanto mais dados, melhores as sugestões.

### 7.4 Demandas

Registro e acompanhamento de demandas observadas nos bairros e comunidades. Cada demanda tem tema, localização, urgência e status de acompanhamento.

**Passos:**

1. Acesse **Gestão → Demandas**.
2. Visualize as demandas com filtros por bairro, tema e status.
3. Registre uma nova demanda com localização, tema e descrição detalhada.
4. Atualize o status conforme a demanda for sendo acompanhada.

### 7.5 Mapa

Visualização geográfica dos dados da campanha em um mapa interativo. Mostra a distribuição de eleitores, apoiadores, lideranças, eventos e demandas por região.

**Passos:**

1. Acesse **Gestão → Mapa**.
2. O mapa carrega centralizado na região da campanha.
3. Use os filtros para escolher o que exibir: eleitores, apoiadores, lideranças, eventos.
4. Clique nos marcadores para ver detalhes do ponto.
5. Use o zoom e arraste para navegar pelo mapa.

## Comunicação

### 8.1 Mensagens

Envio de mensagens para eleitores e apoiadores. Permite criar mensagens individuais ou em massa, usando modelos pré-definidos ou texto livre. Inclui histórico de envios.

**Passos:**

1. Acesse **Comunicação → Mensagens**.
2. Selecione os destinatários (individual, por bairro, por tag ou todos os apoiadores).
3. Escolha um **modelo de mensagem** ou escreva o texto manualmente.
4. Revise a mensagem e clique em **"Enviar"**.

**Alerta:** Mensagens em massa devem respeitar a legislação eleitoral. O sistema não envia mensagens via WhatsApp automaticamente — ele gera o conteúdo para que a equipe distribua manualmente.

### 8.2 Modelos de Mensagem

Biblioteca de modelos reutilizáveis para padronizar a comunicação da campanha. Os modelos podem conter variáveis (nome do eleitor, bairro, etc.) que são preenchidas automaticamente.

**Passos:**

1. Acesse **Comunicação → Modelos de mensagem**.
2. Veja os modelos existentes organizados por categoria.
3. Clique em **"Novo modelo"** para criar. Use `{nome}` para variáveis dinâmicas.
4. Para editar um modelo existente, clique nele e altere o conteúdo.

### 8.3 Avisos Internos

Comunicação interna da equipe de campanha. Avisos são notificações enviadas para todos os membros ou para papéis específicos.

**Passos:**

1. Acesse **Comunicação → Avisos internos**.
2. Veja o mural de avisos com data, autor e destinatários.
3. Clique em **"Novo aviso"**, escreva o conteúdo e selecione os destinatários.

### 8.4 Respostas

Módulo de **sugestão de respostas por IA** para atender cidadãos. Cole a mensagem recebida de um eleitor e a IA gera uma sugestão de resposta alinhada com as diretrizes e propostas da campanha.

**Passos:**

1. Acesse **Comunicação → Respostas**.
2. Cole a mensagem do cidadão no campo de texto.
3. Clique em **"Gerar resposta"**. A IA analisará a mensagem e sugerirá uma resposta.
4. Revise, edite se necessário, e copie a resposta para enviar ao cidadão.

**Dica:** A qualidade das respostas depende das Diretrizes e Base de Conhecimento cadastradas. Quanto mais completas, mais alinhadas serão as respostas.

## Jurídico

### 9.1 Tira-dúvidas Jurídico

Consulte a **legislação eleitoral brasileira** usando IA. O sistema tem o Código Eleitoral, resoluções do TSE e jurisprudência na base de conhecimento, e responde perguntas em linguagem acessível.

**Passos:**

1. Acesse **Jurídico → Tira-dúvidas**.
2. Digite sua pergunta jurídica no campo de texto. Exemplos: "Pode fazer comício depois das 22h?", "Quais são os limites de gasto para deputado estadual?"
3. Clique em **"Consultar"**. A IA responderá citando a base legal aplicável.
4. O histórico de consultas fica salvo para referência futura.

**Alerta:** As respostas da IA são orientativas. Para decisões jurídicas formais, consulte sempre o advogado responsável pela campanha.

### 9.2 Dossiê Jurídico

Repositório de documentos e anotações jurídicas da campanha. Organize processos, pareceres, notificações e outros documentos jurídicos relevantes.

**Passos:**

1. Acesse **Jurídico → Dossiê jurídico**.
2. Visualize os documentos organizados por tipo e data.
3. Adicione novos documentos ou anotações clicando em **"Novo registro"**.

### 9.3 Calendário Eleitoral

Linha do tempo com todos os **prazos e datas importantes** do calendário eleitoral oficial do TSE para 2026. Inclui prazos de registro de candidatura, início e fim de propaganda, datas de debates, votação, etc.

**Passos:**

1. Acesse **Jurídico → Calendário eleitoral**.
2. Visualize os prazos em formato de linha do tempo.
3. Datas passadas ficam esmaecidas. Datas futuras próximas ficam destacadas.

**Dica:** Os prazos do calendário eleitoral também aparecem nos alertas da Sala de Decisão quando estão próximos.

## Inteligência

### 10.1 Diretrizes da Campanha

Defina as **diretrizes estratégicas** que orientam toda a comunicação e IA da campanha: tom de voz, posicionamentos, o que dizer e o que evitar, temas prioritários. As diretrizes são injetadas em todos os prompts de IA do sistema.

**Passos:**

1. Acesse **Inteligência → Diretrizes da Campanha**.
2. Preencha as seções: **Tom de voz**, **Posicionamentos**, **Temas a evitar**, **Público-alvo**.
3. Cada diretriz pode ser **aprovada** pelo coordenador para entrar em vigor.
4. Diretrizes aprovadas influenciam todas as respostas e sugestões da IA.

**Alerta:** Diretrizes bem definidas são fundamentais para a qualidade da IA. Dedique tempo para preenchê-las com cuidado.

### 10.2 Monitoramento

Monitore **notícias e menções** sobre a campanha, candidato e concorrentes na internet. O sistema busca automaticamente em fontes de notícias e analisa o sentimento de cada menção usando IA.

**Passos:**

1. Acesse **Inteligência → Monitoramento**.
2. Veja as notícias mais recentes com indicação de sentimento (positivo/neutro/negativo).
3. Use os filtros para buscar por período, fonte, tema ou sentimento.
4. Clique em uma notícia para ver o resumo da IA e o link para a fonte original.
5. Notícias relevantes podem gerar **alertas** automáticos.

### 10.3 Registrar Denúncia

Registre denúncias de irregularidades eleitorais observadas por agentes de campo ou recebidas por cidadãos. O sistema organiza as denúncias com evidências e encaminhamento.

**Passos:**

1. Acesse **Inteligência → Registrar denúncia**.
2. Preencha os campos: tipo de irregularidade, local, data/hora, descrição detalhada.
3. Anexe evidências (fotos, vídeos, documentos) se disponíveis.
4. Clique em **"Registrar"**. A denúncia ficará disponível no dossiê jurídico.

### 10.4 Alertas

Central de alertas do sistema. Alertas são gerados automaticamente a partir do monitoramento de notícias, prazos do calendário eleitoral e outros eventos que exigem atenção.

**Passos:**

1. Acesse **Inteligência → Alertas**.
2. Visualize os alertas ativos, ordenados por prioridade.
3. Clique em um alerta para ver os detalhes e tomar ação.
4. Marque como **"resolvido"** após tratar o alerta.

### 10.5 Saúde das Fontes

Painel de status das fontes de monitoramento. Mostra se cada fonte de notícias está operacional, quando foi a última coleta bem-sucedida e se há falhas recentes.

**Passos:**

1. Acesse **Inteligência → Saúde das fontes**.
2. Veja o status de cada fonte: operacional (verde), degradada (amarelo) ou offline (vermelho).
3. Fontes com problemas exibem o motivo da falha e sugestão de correção.

### 10.6 Concorrentes

Cadastre e acompanhe os concorrentes da campanha. Para cada concorrente, registre nome, partido, pontos fortes, pontos fracos e acompanhe as menções no monitoramento.

**Passos:**

1. Acesse **Inteligência → Concorrentes**.
2. Veja a lista de concorrentes cadastrados com resumo de menções.
3. Clique em **"Novo concorrente"** para cadastrar.
4. No perfil do concorrente, veja o histórico de menções filtrado automaticamente pelo monitoramento.

### 10.7 Base de Conhecimento

Repositório de conhecimento da campanha organizado por **temas**. Cada tema pode ter itens (textos, dados, argumentos), públicos-alvo específicos e regiões prioritárias. A base alimenta todas as respostas da IA.

**Passos:**

1. Acesse **Inteligência → Base de conhecimento**.
2. Visualize os temas cadastrados (ex: Saúde, Educação, Segurança).
3. Clique em um tema para ver e editar seus itens, públicos-alvo e regiões.
4. Para criar um novo tema, clique em **"Novo tema"**.
5. Adicione itens ao tema com título e descrição detalhada.

**Dica:** A Base de Conhecimento é o coração da IA. Quanto mais completa e atualizada, melhores serão os briefings, recomendações e respostas geradas.

### 10.8 Propostas

Cadastro das propostas de governo do candidato. Cada proposta tem título, descrição, tema vinculado, público beneficiado e status (rascunho, aprovada, publicada).

**Passos:**

1. Acesse **Inteligência → Propostas**.
2. Veja a lista de propostas com tema, status e resumo.
3. Clique em **"Nova proposta"** para cadastrar.
4. Vincule a proposta a um tema da Base de Conhecimento para melhor integração com a IA.

### 10.9 Narrativas

Análise de **narrativas** em circulação sobre temas eleitorais. A IA identifica narrativas dominantes a partir do monitoramento de notícias e sugere contra-narrativas alinhadas com a campanha.

**Passos:**

1. Acesse **Inteligência → Narrativas**.
2. Veja as narrativas identificadas com análise de sentimento e alcance.
3. Clique em **"Analisar narrativas"** para a IA gerar uma nova análise.
4. Para cada narrativa negativa, a IA sugere pontos de contra-argumentação.

### 10.10 Código Eleitoral

Consulta à **base normativa eleitoral** integrada ao sistema. Inclui o Código Eleitoral, Lei das Eleições, resoluções do TSE e normas relacionadas. Permite busca por artigo, tema ou palavra-chave.

**Passos:**

1. Acesse **Inteligência → Código eleitoral**.
2. Use a busca para encontrar artigos específicos ou temas (ex: "propaganda antecipada").
3. Navegue pelos capítulos e seções da legislação.

## Marketing

### 11.1 Marketing (Hub)

Página central de marketing com acesso rápido às funcionalidades: criação de conteúdo com IA, adaptação de mensagens para diferentes canais, sugestão de público, geração de imagens e avaliação de peças existentes.

**Passos:**

1. Acesse **Marketing → Marketing**.
2. Escolha a funcionalidade desejada: **Gerar conteúdo**, **Adaptar mensagem**, **Gerar imagem** ou **Avaliar peça**.

#### Gerar Conteúdo com IA

1. Descreva o que você precisa (ex: "post para Instagram sobre educação").
2. Selecione o canal (Instagram, Facebook, WhatsApp, Twitter).
3. A IA gera o conteúdo alinhado com as diretrizes e base de conhecimento da campanha.
4. Revise, edite e salve como peça de conteúdo.

#### Adaptar Mensagem

1. Cole uma mensagem existente que deseja adaptar.
2. Selecione o canal de destino (Stories, Post, WhatsApp, etc.).
3. A IA adapta o tom, formato e tamanho para o canal escolhido.

#### Gerar Imagem

1. Descreva a imagem que deseja (ex: "família brasileira em praça pública, clima de esperança").
2. Selecione o formato: Stories (9:16), Post (1:1), Facebook/Twitter (16:9).
3. A IA gera a imagem usando Gemini. A imagem vem **sem texto e sem rostos identificáveis** — o overlay legal é adicionado manualmente pela equipe.

**Alerta:** A geração de imagem requer chave Gemini configurada em Cadastro de Campanha → Chaves de API.

### 11.2 Impulsionamento (Ads)

Planejamento de **impulsionamento de anúncios** no Meta Ads (Instagram/Facebook). A IA gera um plano completo com segmentação de público, distribuição de orçamento, cronograma e métricas esperadas.

**Passos:**

1. Acesse **Marketing → Impulsionamento**.
2. Descreva a peça que será impulsionada (ou selecione uma peça existente).
3. Defina o **objetivo** (alcance, tráfego, engajamento, visualizações, conversão, mensagens, seguidores).
4. Informe o **público prioritário** ou clique em **"Sugerir público"** para a IA recomendar.
5. Defina o **orçamento total** (R$) e o **prazo** (dias).
6. Clique em **"Gerar plano"**. A IA criará um plano detalhado de impulsionamento.
7. Revise o plano e use-o como guia para configurar a campanha no Meta Ads Manager.

**Dica:** A sugestão de público usa a Base de Conhecimento para recomendar segmentações baseadas nos públicos-alvo e regiões cadastrados em cada tema.

### 11.3 Peças de Conteúdo

Biblioteca de todas as peças de conteúdo da campanha (posts, stories, panfletos, vídeos, etc.). Cada peça pode passar por **revisão de compliance eleitoral por IA**, que verifica se o conteúdo está em conformidade com a legislação.

**Passos:**

1. Acesse **Marketing → Peças de conteúdo**.
2. Veja a biblioteca com miniaturas, tipo, canal e status de revisão.
3. Para adicionar uma nova peça, clique em **"Nova peça"**.
4. Preencha tipo (imagem, vídeo, texto), canal, conteúdo/legenda e envie a arte se houver.
5. Para revisar, clique em **"Revisar compliance"**. A IA verificará:
   - Presença de identificação legal obrigatória (nome de urna, número, CNPJ, selo IA)
   - Conteúdo potencialmente ilegal (ofensas, fake news, uso irregular de símbolos)
   - Conformidade com resoluções do TSE sobre propaganda eleitoral
   - Adequação de imagens (se a peça contém arte, a revisão usa visão computacional)
6. O resultado da revisão aparece como checklist com itens OK e itens que precisam de correção.

**Alerta:** Peças com imagem exigem chave Gemini para a revisão visual. Peças somente texto podem ser revisadas com qualquer provedor de IA configurado.

## Dicas e Boas Práticas

### Configuração Inicial Recomendada

1. **Cadastro de campanha** — Preencha todos os dados do candidato. São usados na revisão de compliance.
2. **Chaves de API** — Configure pelo menos uma chave de IA (Gemini é suficiente para a maioria das funcionalidades).
3. **Diretrizes** — Defina tom de voz, posicionamentos e temas a evitar. Impacta toda a IA do sistema.
4. **Base de Conhecimento** — Cadastre os temas principais com propostas, públicos-alvo e regiões.
5. **Usuários** — Convide a equipe com os papéis adequados.
6. **Concorrentes** — Cadastre os principais concorrentes para o monitoramento.

### Segurança

- Use **senhas fortes** (mínimo 8 caracteres, misturando letras, números e símbolos).
- Não compartilhe seu login com outras pessoas. Cada membro deve ter seu próprio acesso.
- As chaves de API são criptografadas no banco de dados. Não as compartilhe por mensagem.
- O sistema mantém **trilha de auditoria** de todas as ações — tudo é rastreável.
- Dados pessoais estão protegidos por RLS (Row Level Security) — cada campanha só vê seus próprios dados.

### Dúvidas Frequentes

**A IA não está respondendo. O que fazer?**

Verifique se há uma chave de API configurada em Cadastro de Campanha → Chaves de API. O sistema tenta Anthropic → OpenAI → Gemini → Grok, nessa ordem. Pelo menos uma precisa estar ativa.

**Posso acessar pelo celular?**

Sim. O sistema é responsivo e funciona em qualquer navegador moderno. Use o menu ☰ para navegar no celular.

**Como trocar de campanha?**

Apenas desenvolvedores da plataforma podem alternar entre campanhas (badge "Dev" no cabeçalho). Usuários regulares pertencem a uma única campanha.

**O que significa "Acesso por convite"?**

Não existe cadastro público. O coordenador de campanha convida cada membro pelo e-mail. Isso garante que apenas pessoas autorizadas tenham acesso.
